# 第三方来源

本插件的米家扫码、云端签名及规格解析参考 MenuBarMijia，固定提交为
`cdd1544394448374531c5bf958eb15295272a00b`。协议以 Python 标准库重新实现。

来源：https://github.com/jryang1997/MenuBarMijia/tree/cdd1544394448374531c5bf958eb15295272a00b

参考文件：`Sources/MijiaCore/MiCloud/`、`windows/src/core/miCloud/`、
`windows/src/core/miCloudCrypto.ts`。回归中的合同夹具和签名向量来自该提交的
`Tests/Fixtures/contracts/` 与 `windows/tests/core.test.ts`。
