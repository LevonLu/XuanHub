# 玄枢菜单图标

主框架“设置 → 外观 → 菜单图标”提供三种选择。保存后由配置热重载生效，
同步改变状态栏中的菜单入口和系统托盘；窗口和可执行文件图标继续使用现有品牌资源。

| 设置名称 | 配置值 `bar.menuIcon` | 来源 |
|---|---|---|
| 原版 | `original` | 原品牌位图蒙版，保持默认行为 |
| 方框枢纽 | `hub` | 方案 A，中空方框连接四条斜臂 |
| 紧凑 H | `compact` | 方案 C，中心 H 连接四条斜臂 |

配置缺失或非法时回退原版。设置草稿的过期保护包含本字段，旧草稿不会覆盖外部改动。
插件私有 `config` 中不保存此选项；宿主通过保留状态 `app.quickMenu.state.menuIcon` 下发，
菜单原地响应，不因图标变化重建插件实例。

## 共用绘制

设置预览与菜单均使用 [`BrandIcon.qml`](../../app/qml/BrandIcon.qml)。
组件公开 `iconStyle` 与 `glyphColor`，未知样式回退原版，所有图形随主题前景色着色。
原版复用宿主资源中的 PNG 透明蒙版；A、C 由原生 Qt Quick 图元直接绘制。
托盘通过 [`BrandIconRenderer.cpp`](../../app/src/BrandIconRenderer.cpp) 按下述同一几何规则用 QPainter 绘制，
使用当前主题前景色，提供 16、20、24、32、40、48、64 像素图像供系统按 DPI 选择。
原版托盘保留原始品牌 PNG；主题变化时 A、C 重绘，Explorer 重建沿用当前选择。

## A 与 C 的几何比例

使用 24×24 网格，中心为 (12,12)，统一线宽 2，圆头半径 1。

| 部分 | A：方框枢纽 | C：紧凑 H |
|---|---|---|
| 中心结构 | 方框外边界 (8,8)–(16,16)，圆角 1.5 | 双柱 (8,8)–(8,16)、(16,8)–(16,16) |
| 中央横梁 | 方框中心透明 | (8,12)–(16,12) |
| 左上斜臂 | (9,9)–(4,4) | (8,8)–(4,4) |
| 其他斜臂 | 关于中心上下、左右镜像 | 关于中心上下、左右镜像 |

图元按 `min(width,height)/24` 等比缩放并居中；A、C 在 24×24 容器内的可见范围为
(3,3)–(21,21)。原版菜单保留 28×28 绘制尺寸，A、C 为 24×24，点击区域均为 40×40。
