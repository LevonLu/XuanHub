# 音乐

在玄枢设置中启用「音乐」，并在 QQ 音乐的「常规设置 → 通知」中打开「显示系统媒体传输控件（SMTC）」。播放歌曲后，状态栏会显示当前歌词。点击歌词或歌名可展开上一曲、播放／暂停、下一曲和播放进度。

「歌词行数」默认为单行。双行模式第一行显示当前句，第二行预告下一句。「双行字号」默认上大下小，也可选择同样大小。栏高不足时自动显示单行。QQ 音乐退出后槽位自动收起。

歌词来自 QQ 音乐的本地 QRC／LRC 缓存，查不到对应曲目时显示歌名。缓存可能在播放开始后才写入。详情弹窗中的播放进度用于查看，拖动时间轴请在 QQ 音乐内操作。

本地 QRC 解码所用的第三方许可随插件分发。见 [THIRD-PARTY-LICENSES.txt](THIRD-PARTY-LICENSES.txt)。
