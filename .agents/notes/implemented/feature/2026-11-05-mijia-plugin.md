# Agent Note: 米家云端设备插件首版

Status: implemented

## Problem

用户需要不依赖 Home Assistant 的米家入口，并尽量覆盖不同型号。逐型号手写界面不能覆盖长尾，
同步扫码等待又会超过 Worker 请求期限，因此设备描述与网络调度需要独立于 QML 回调。

## Decision

py_mijia 使用 Python 标准库接入扫码和 MIoT 云端协议。一个后台线程串行处理网络，
主线程每秒接收结果并保存会话。设备采用类型卡片加通用属性详情；真实规格决定权限、枚举、范围和步长。
未知语义写入须确认，内部配置与门锁不执行。写入后回读，不在请求超时后自动重发。

会话整体使用宿主密钥服务保存，成功后才宣布已登录。QML 私有存储按账号摘要保存收藏与状态栏属性。
取消登录和退出递增代次，后台迟到结果不可恢复旧账号。状态栏只固定一个可读属性。

面板底部明确提供“任务栏显示”，选择一台设备的一项可读属性，并预览名称、单位及 0–3 位
最大小数位；详情也使用文字按钮快速固定。显示格式随账号私有偏好保存，旧偏好缺字段时使用默认值。
选择器临时复用既有详情查询，取消后恢复原浏览目标；原设备页不显示临时目标的控件。
保存新选择后按新设备与属性匹配快照，迟到的旧读数不能覆盖新选择。切回在线数量保留格式选项。

面板参考用户提供的 MenuBarMijia 运行截图，采用家庭摘要、房间分段与双列卡片。
视觉使用玄枢既有的 FluentWinUI3 控件、4/8px 圆角及主题色板，卡片采用平面边框。
按钮、搜索、家庭选择和详情编辑器沿用原生悬停与焦点；滑块仅简化轨道以避免宽范围产生密集刻度，
仍保留 Fluent 手柄和规格步进。明暗资源由宿主统一设置，不在插件中改变应用主题。
空调跨列显示目标温度和步进按钮，单路电源可以直接切换，传感器优先显示实际读数。
列表快照每台最多携带十项常用属性，避免全量规格使 IPC 快照膨胀；详情保留完整控件。
卡片操作沿用后端规格校验、通用确认和回读回执，不自行猜测属性或乐观更新设备状态。
多路开关仍进入详情逐路控制，摘要只汇总可见范围的有效读数，不填充演示数值。
多路数量取完整规格，不能因十项摘要上限误判为单路并直接切换。

## Alternatives considered

- Home Assistant 可统一多个厂商，但用户未部署，首版选择米家直连。
- 逐型号卡片能精细定制，但覆盖有限，因此类型层负责常用界面，通用层承接长尾。
- 第三方 Python 米家库可减少协议代码，但会增加分发依赖；首版参考 MenuBarMijia 的已测试协议并使用标准库。
- PUSH_VALUES 可降低刷新延迟，但会话持久化必须在主线程执行；首版保留每秒 update 交接，不扩展宿主接口。
- 纯文本列表实现简单，但缺乏设备品类和状态层次；采用卡片并保留搜索、列表切换与通用详情。
- 参考图中的语音和场景入口超出首版能力，不放置无实际行为的装饰按钮。
- 宿主静态 schema 适合刷新周期，但不能列出账号实时设备和属性；选择和格式统一放在弹窗，
  避免配置与账号私有偏好维护两套显示状态。

## Verification

协议回归匹配固定签名向量与上游合同夹具，覆盖分页去重、共享家庭补查、真实父设备绑定、
数值步长与枚举校验、写后回读、限流退避、排队取消和凭据失败。退出不受后台队列满阻塞，
主线程的凭据错误不被后台快照覆盖。完整 Python 插件回归与真实 Worker 生命周期通过。

QML 交互回归验证账号间收藏和固定读数隔离、通用操作确认、操作回执及开关等待真实回读，
并渲染扫码页与深浅色详情。真实米家接口返回二维码，用户已完成扫码；独立便携宿主
通过重启自动恢复会话并发现实际账号设备。实际读写回执继续由用户操作验收，不由发现结果推断。
测试副本额外记录无账号、设备名称与凭据的兼容性摘要；该探针不进入插件源代码或分发目录。

卡片回归使用合成设备验证空调加温、插座电源的目标设备与属性、等待真实回读、房间搜索筛选、
单列窄屏及深浅配色；Windows 原生 QML 渲染用于检查字体、图标与卡片间距。
离线卡片保留旧值并标记缓存，卡片及详情同步显示待执行状态；视觉检查不发起真实设备控制。

任务栏选择回归覆盖可读属性过滤、临时查询与原详情隔离、格式预览、保存／取消、账号隔离、
重新实例化恢复及清除后立即显示在线数；只使用合成设备，不改动真实设备状态。

云端缓存读取不改变目录的在线状态，并沿用服务端读数时间；旧值在详情和状态栏标记失效。
已可读的当前设备优先刷新，其他卡片的规格解析不会阻塞其读取。

## Consequences

云端私有接口可能变化；规格存在但云端不一定允许读写。按发现、读取、控制分别记录结果。
后台请求只能协作取消，必须丢弃旧代次结果。离线夹具和 QML Smoke 不代表真实设备验收。
类型卡片与通用详情复用校验，扩大覆盖面而不猜测属性编号；代价是未知语义控件需要确认，
规格不完整时只显示解释。缓存仅保存在内存中，重启需要重新获取规格。
真实账号的覆盖结果以本次独立宿主记录为准；DPI、多屏边界和未持有设备仍需人工验收。
