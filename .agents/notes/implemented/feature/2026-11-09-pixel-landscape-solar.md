# Agent Note: 像素风景跟随当地太阳

Status: implemented

## Problem

固定钟点的晨昏无法反映纬度与季节；太阳位置固定，切换整套时段也无法表达真实的一天。

## Decision

升级 auto，使用 Windows 原生异步定位和本地太阳计算。首次授权由前台弹窗点击触发；后台不触发授权。系统位置缓存有效二十四小时，失败时依次使用有效缓存、手动位置、旧时段；拒绝授权使缓存失效。插件私有存储不改配置，关闭插件取消请求。

沿用六场景、低频共享时钟和两层 Canvas。天空及像素太阳在地形下方，太阳移动不重绘地形；按太阳高度混合有限色板并渐显星灯。最终色板值相同不刷新地形；晨昏色板在正午和太阳午夜均连续，避免高纬度低太阳发生跳色。天气和手动时段保持原语义，暂停装饰动画仍校准现实光照。

WinRT 操作由短周期 Qt 定时器检查完成状态，取消后释放操作对象；不注册跨线程进入 DLL 的完成委托。配置改变或插件停止递增请求代次，过期结果不能落入新状态。三十秒校时之外，原生 WM_TIMECHANGE 与恢复供电广播合并为事件循环中的一次重同步，暂停动画也不会延迟到下一轮校时；停止时解除消息过滤器。

太阳计算用 UTC 绝对时刻，日出日落求根覆盖电脑当前时区的一整天（包括夏令时的二十三或二十五小时）。位置与时间分离，坐标缓存不会缓存昨日天文结果。月亮仍属装饰，左右方向是统一艺术约定，不表示真实朝向。

手动位置提供离线国家／地区和城市预设，共十三组七十五座城市，其中中国四十九座。自绘设置页通过既有 SettingsPluginProxy 写入纬度、经度与手动启用开关，不新增运行时预设配置键；重新打开时从坐标识别预设，手工改坐标后显示自定义。选择国家只筛选列表，不改已有坐标；选择城市不改系统优先或仅手动的定位方式。清单保留 schema 作为保存校验依据，非法坐标文本写入草稿供其拒绝保存，避免界面显示新值而实际保存旧值。

## Historical audit

[原风景决定](../../implemented/feature/2026-11-08-pixel-landscape.md)部分重叠：本篇取代其自动模式固定时段和完全无外部位置来源的边界，其构图、按需弹窗、低频渲染继续成立。[窗口生命周期](../../implemented/architecture/2026-11-02-runtime-memory-lifetime.md)与[弹窗定位](../../implemented/bug-fix/2026-10-30-quick-menu-popup-placement.md)继续适用，不归档。其余定位命中均为窗口定位，与地理位置无关。

## Alternatives considered

在线日出日落 API 可免维护计算，但增加网络故障和服务依赖，故在取得坐标后本地计算。IP 定位免系统授权，但 VPN 会偏移城市，故采用 Windows 定位与手动兜底。Qt Positioning 可封装系统接口，但当前环境未安装且需额外部署，因此直接使用 Windows SDK。全图逐帧重绘简单，但会让太阳运动引起不必要的地形重绘，故分离天空与太阳。

单一 schema 城市枚举改动较少，但无法表达国家筛选和成对填入坐标；扩展宿主表单联动协议会扩大 SDK 契约，因此使用已有自绘设置入口并保留原配置字段。在线城市搜索覆盖更全，但增加网络与输入等待，本次选择附带来源许可的 GeoNames 精选坐标；列表外地点继续手动输入。

## Testing

独立 USNO 参考覆盖六个地点日期组合，日出、日落、太阳正午与民用晨昏共三十项事件最大偏差四十四秒。极区、闰日、夏令时、跨午夜与连续性另有回归。定位使用可控提供者验证拒绝、超时、过期、撤销、停止和旧请求结果，Windows 原生提供者另做已授权真实请求与取消检查。

六场景、日内多时刻、暂停、栏上与弹窗同步、中英文窄屏及静态重绘预算使用实际 QML 渲染。原生恢复广播的消息处理测试与真实休眠是不同证据层级。构建、CTest、CLI、缩放图、性能样本和设备验收缺口集中见[太阳光照验证](../../../../docs/pixel-landscape-solar-validation.md)。

城市设置通过实际 ComboBox 键盘选择验证国家筛选不写草稿、城市成对填入坐标、保留未知键和其他设置、旧配置打开零写入、重开识别城市及代理切换防误写。坐标编辑保留负号和小数点中间态；无效输入以包含原文的非数值草稿保存，由既有 double schema 拒绝提交，修正后恢复普通数字。中英文 360/620 宽度设置页有实际 QML 检查图。

## Consequences

本地天文计算不依赖在线日出服务；新配置缺失时可继续使用旧画面。Windows 定位仍取决于系统设置、设备与网络，首次授权必须在前台。插件私有缓存包含坐标和时间戳，只有 storage.private 权限允许时写入，不写入用户配置或日志；缓存失败不阻止本次有效位置用于光照。

Canvas 色板变动仍有重绘成本，有限量化与最终色板去重限制其频率；日出日落采用标准地平线模型，不模拟海拔、山体地平线和实际气象折射。实测与自动测试不能替代首次系统授权、物理 DPI 和休眠设备验收，未执行项明确保留，不自动发布或改动用户启用配置。
