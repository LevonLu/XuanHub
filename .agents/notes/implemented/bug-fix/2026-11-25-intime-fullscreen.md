# Agent Note: InTime 的休息遮罩覆盖每块屏幕

Status: implemented

## Problem

休息时只有状态栏所在屏幕出现遮罩，任务栏也留在遮罩外。插件只创建一个窗口，尺寸取自普通弹窗使用的可用工作区。

## Decision

`InTime.qml` 按 `Qt.application.screens` 为每块屏幕建立独立的置顶全屏窗口。显示前绑定目标屏幕、虚拟桌面原点与完整尺寸。Qt 6.9.3 在 Windows 软件渲染下首次显示透明全屏窗口时，省略初始宽高能复现原生异常；指定宽高后同一用例通过。

所有窗口共用 Worker 的休息状态、倒计时和一条裁剪动画。在获得焦点的窗口按 Esc 会结束同一轮休息。退出动画完成或插件卸载时释放所有窗口。

## Alternatives considered

一个覆盖虚拟桌面的窗口可以复用原有窗口，但不同缩放比例的屏幕各自有逻辑坐标，倒计时也应分别在每块屏幕上居中。

[状态栏弹窗的可用工作区](2026-11-02-popup-native-monitor.md)适合让菜单避开任务栏。扩大宿主提供的工作区会同时改变普通弹窗的定位，而且仍然只提供一块屏幕。

## Consequences

每块屏幕在休息期间各自绘制背景和倒计时，工作期间没有遮罩窗口。任务栏也在覆盖范围内，提前结束休息可在任一遮罩上按 Esc。

## Verification

`xuanhub_intime_overlay_tests` 使用带负坐标、不同缩放的双屏离屏配置，检查全屏几何、置顶标志、结束休息、两屏 Esc 和插件卸载。

另在独立 Windows 桌面用 Qt 6.9.3 的默认渲染和软件渲染运行同组用例，两次都测得两个可见置顶 HWND 的物理矩形分别与两块显示器完全重合。当前工作桌面上 Explorer 的实际叠放效果留给宿主重启后确认。
