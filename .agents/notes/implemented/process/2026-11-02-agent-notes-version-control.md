# Agent Note: 决策笔记与外部技能的版本管理

Status: implemented

## Problem

项目已使用决策笔记记录重要改动，但本地安装的技能与产出的项目笔记都出现在待提交列表中，缺少明确的版本管理边界。用户要求笔记随相关代码提交，技能本体不进入项目仓库，并为其他维护者提供上游获取入口。

## Decision

- `.agents/notes/` 纳入版本控制，笔记的新增、修改、迁移和归档与对应代码或流程改动在同一次提交中完成。
- `.gitignore` 只排除本地的 `.agents/skills/write-notes-like-deepseek/`，不忽略整个 `.agents/` 或全部技能，保留已有项目技能的跟踪方式。
- `AGENTS.md` 记录上游仓库 `https://github.com/czm15053/write-notes-like-deepseek`、源目录 `skills/write-notes-like-deepseek/`、本地安装路径和已验证提交 `72573a5b179de7798bbb7c4aeacdc0df6bf62439`，供维护者自行安装和升级。
- `pixi run verify-notes` 继续调用本地技能脚本；运行前需按 `AGENTS.md` 安装技能，不自动下载或提交技能副本。

## 历史决策检索

按“技能、skill、校验、提交、忽略、gitignore”检索活跃笔记。[项目内启用决策笔记与统一校验](2026-10-30-project-agent-notes.md)与本篇部分重叠：保留其项目内安装、笔记结构和 Pixi 校验入口，本篇补充版本控制与技能获取方式，双方互链。命中的用量插件与分发安全笔记属于不同主题，继续保留。

## Alternatives considered

- **将技能副本与项目一起提交**：检出仓库后即可使用相同脚本，减少首次安装步骤；但用户明确要求不提交技能本体，因此改为保留上游地址与固定提交号。
- **忽略整个 `.agents/`**：规则简单，能一次屏蔽本机代理文件；但会漏交决策笔记，并隐藏已有项目技能的新增文件，因此只忽略指定技能目录。

## Consequences

- **收益**：设计理由与对应改动在 Git 中共同留存；项目无需维护外部技能副本，其他维护者仍可按固定来源安装。
- **代价**：新检出的工作区需要先安装技能才能运行笔记校验；更新上游版本时需同步维护文档中的提交号并重新校验。
- **边界**：忽略规则保留现有凭据与缓存排除项；笔记和代码同次提交由维护流程保证，目前未新增 Git 钩子或 CI 门禁。

## Verification

- 使用 Git 忽略检查确认技能文件被排除、决策笔记可纳入提交，已有项目技能的跟踪方式不变。
- 在项目根目录运行 `pixi run verify-notes`，校验目录与相对链接、格式及归档封印；运行 `git diff --check` 检查补丁格式。
- 本次仅修改开发流程、忽略规则与笔记，不涉及应用代码，无需 Qt/MSVC 构建或宿主运行验收。
