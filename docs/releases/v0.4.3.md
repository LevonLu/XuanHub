# XuanHub v0.4.3

v0.4.3 汇总 v0.4.2 之后的菜单、Token Usage、倒计时与常驻资源优化。

## 主要更新

- 玄枢菜单使用统一的分段控件切换“任务栏模式 / 独立状态栏”和“浅色 / 深色”，当前选项清晰可见，重复点击当前项不再重复发出切换命令。
- Token Usage 合并工具用量与账户额度，支持按列组合 Token、套餐限额和账户余额，并保留旧 Usage Hub 配置的安全迁移路径。
- 优化 Token Usage 弹窗的信息层级、深浅色外观、工具卡片和额度进度条；账户页隐藏未配置及尚无有效数据的自动探测条目，保留已配置手动账户的错误提示和有效缓存。
- 按需创建设置页和插件弹窗内容，关闭后释放视图；保留异步任务模型，并避免 Python worker 标准输出导致宿主缓冲增长。
- 按原生窗口所在屏幕定位弹窗，改进 taskbar 和多屏场景中的屏幕选择。
- 倒计时支持自定义悬浮提示和发薪日计算，可配置节假日与补班日期。

## 运行与下载

- Windows 10 / 11 x64。
- 正式包为 `XuanHub-v0.4.3-portable-x64.zip`，内置 Python 解释器、标准库、插件依赖和 MSVC 运行库。
- 解压后运行 `XuanHub.exe`。更新旧版本前先退出已有实例，保留自己的配置和凭据文件，避免被默认配置覆盖。
- 发布包从干净的检出目录构建，使用仓库内置默认配置，不包含打包机器的个人配置、日志、凭据或缓存。

## 发布验证

- 在独立检出目录执行 `pixi run build` 和 `ctest --test-dir build/default -C Release --output-on-failure`。
- 菜单回归覆盖两种显示模式、深浅色切换、重复点击、首次定位、动态内容高度及跨插件互斥。
- 便携包经过 staging 与 ZIP 安全门禁，再在全新解压目录检查 Python、第三方依赖和随包插件。
- 同时提供 `XuanHub-v0.4.3-SHA256SUMS.txt`，下载后可校验 ZIP 的 SHA-256。
- 自动测试和独立窗口截图不代替真实 Shell 嵌入及全部 DPI 场景的人工验收。
