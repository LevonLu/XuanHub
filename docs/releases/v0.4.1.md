# XuanHub v0.4.1

v0.4.1 是 v0.4.0 之后的体验与诊断补丁版本，保持现有插件 SDK 与配置格式兼容。

## 主要更新

- 引入 Theme Schema v2：主题可声明栏、区域和插件槽的圆角、间距、边框与装饰令牌。
- 支持可选的可信 Bar QML 外壳扩展，增加路径越界防护、模式约束和内置外壳回退。
- 新增 `floating-capsules` 与 `glass-panel` 主题，并改进 sysinfo 的自适应尺寸、详情指标和趋势图。
- 精简玄枢快速菜单宽度、间距和圆角，统一使用托盘图标，并移除容易被误认为可展开的箭头。
- 为其他插件动态加入的菜单操作增加总开关和逐项控制。
- 修正插件启动耗时指标：C++/QML 加载耗时完成后锁定，Python 记录到首次 `update()` 成功的真实 Worker 启动耗时，不再随运行时间增长。

## 发布验证

- `pixi run build`
- `ctest --test-dir build/default -C Release --output-on-failure`（38/38 通过）
- 真实宿主中验证主题、玄枢菜单设置页与 Python 插件启动耗时。
