# XuanHub v0.6.0

## 本版更新

- **InTime 休息提醒**在每块显示器上显示全屏遮罩，覆盖任务栏。所有屏幕共用倒计时，在任意一块屏幕按 Esc 都能结束休息。
- **任务栏模式**默认保留 Windows 开始按钮的点击空间。插件超出可用宽度时，可用滚轮或触控板横向浏览。
- **QQ 音乐**新增状态栏同步歌词与播放控制。在设置中启用“音乐”即可使用；插件从本机 QQ 音乐缓存读取歌词，找不到歌词时显示曲名。会话消失时自动收起槽位。
- **朝暮风景**新增「窗外城市」「水面以下」「取经路上」，可在插件设置中切换。欣赏弹窗与栏上的动画保持同步。
- **插件 SDK**支持通过可选布尔属性 `barItemVisible` 动态收起或恢复槽位。收起期间 ViewModel 继续运行。

## 下载与升级

Windows 10 / 11 x64 用户可下载 `XuanHub-v0.6.0-portable-x64.zip`，解压到可写目录后运行 `XuanHub.exe`。包内包含 Python、内置插件依赖与 MSVC 运行库。随附的 `XuanHub-v0.6.0-SHA256SUMS.txt` 用于校验下载。

使用官方 v0.5.0 便携包的用户可在托盘或设置中选择“检查软件更新”。更早的版本需手动迁移并保留自己的配置和插件数据。[升级与恢复说明](https://github.com/LevonLu/XuanHub/blob/v0.6.0/docs/app-update.md)

[查看自 v0.5.0 以来的完整变更](https://github.com/LevonLu/XuanHub/compare/v0.5.0...v0.6.0)
