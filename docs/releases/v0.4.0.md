# XuanHub v0.4.0

v0.4.0 是一次插件框架与生态版本更新，包含 v0.2.1 之后的全部 157 个开发提交。

## 主要更新

- 发布原生插件 SDK V2：加载代码前校验 Manifest、版本、架构、路径、依赖和能力，并继续兼容 V1。
- 增加作用域化 HostServices 与权限说明，统一日志、通知、私有存储、密钥、链接和设置入口。
- 发布 EventBus V2：异步作用域、保留状态、请求响应、跨命名空间权限、取消和背压。
- 完善配置系统：增量生命周期、原地热配置、扩展 Schema、配置迁移、最终校验和嵌套密钥事务。
- 提供标准插件弹窗、声明式动作与 appbar 响应式布局/溢出菜单。
- 升级 Python Bridge Protocol V2：异步调用结果、进度、取消、主动推送、依赖 doctor 和离线私有环境。
- 增加 `.xuanplugin` 安装包、确定性打包、ECDSA P-256 签名、版本化安装、回滚、卸载和静态更新源。
- 提供 `create/validate/test/run/doctor/package` 开发者 CLI、QML Smoke、稳定错误码和脱敏诊断导出。
- 完善中英多语言、设置页信息密度、内置玄枢菜单插件及框架/插件开发文档。

## 兼容与运行要求

- Windows x64，原生插件使用 MSVC 2022、Qt 6.9.3 和动态 CRT。
- 新生成的 SDK V2 插件最低宿主版本为 0.4.0；既有 `IBarPlugin/1.0` 插件继续兼容。
- Bundle 便携包自带 Python 解释器与标准库；非 Bundle 运行 Python 插件需要 CPython 3.12 或更高版本。
- 原生 DLL 与宿主同进程，权限声明是信任说明；第三方不受信任逻辑优先使用 Python 隔离 Worker。

## 发布验证

- Release 全量构建。
- `ctest --test-dir build/default -C Release --output-on-failure`。
- Bundle 便携包的 staging 安全门禁与最终 ZIP 独立扫描。
- SHA-256 随 GitHub Release 资产摘要发布。
