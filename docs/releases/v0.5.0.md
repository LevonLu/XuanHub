# XuanHub v0.5.0

v0.5.0 新增 GitHub 宿主一键更新与失败回滚，并带来朝暮风景、米家设备插件、插件拖拽排序和首页运行截图。

## 主要更新

- **宿主一键更新**：设置“通用 → 软件更新”和托盘提供检查入口；从官方 GitHub 正式 Release 下载便携包，校验大小、SHA-256、发行清单及本地冲突，再由独立更新器在宿主退出后替换和重启。替换或启动失败时恢复旧文件，保留配置、密钥、插件数据与第三方文件。
- **朝暮风景**：支持山间小屋、海边灯塔、夜雨街角、湖畔营地、田野铁道和空中浮岛六种像素场景，提供宽幅风景条、欣赏弹窗与可选画框；支持当地太阳光照、城市预设、手动时段和天气，以及可配置的朝阳与晚霞。
- **米家插件**：支持米家云设备发现、家庭与房间筛选、收藏、设备详情和适配控件，可把一个设备的一项读数固定显示到状态栏。具体设备控制范围以插件说明和实际规格为准。
- **设置与外观**：支持同一区域内已启用插件的拖拽排序，以及状态栏菜单与托盘图标选择。
- **Python 插件**：补齐密钥服务接口，供米家等插件使用隔离 Worker 与宿主密钥库。
- **文档**：仓库首页新增六张实际运行截图，展示深浅色状态栏、系统监控、朝暮风景及设置界面。

## 运行与升级

- Windows 10 / 11 x64。
- 下载 `XuanHub-v0.5.0-portable-x64.zip`，内置 Python 解释器、标准库、插件依赖和 MSVC 运行库，解压后运行 `XuanHub.exe`。
- **v0.5.0 是一键更新基线版本**。此前的历史便携包没有发行清单，需要手动迁移一次；先退出旧版、备份配置与凭据，再使用新版。不要用包内默认配置覆盖自己的 `config.json`、`secrets.json` 和插件数据。
- 从该基线开始，后续正式版本可经软件更新入口安装；本地修改或删除官方文件、新增路径冲突等情况会阻止更新。更新不会保存设置草稿，请先保存需要保留的更改。
- 发布包采用仓库内置默认配置，不包含打包机器的个人配置、日志、凭据或缓存。截图中的插件组合可按需启用。
- 更新与恢复边界见[软件更新说明](../app-update.md)，米家设备兼容范围见[插件说明](../../plugins_py/mijia/README.md)。

## 发布验证

- 从独立检出目录构建 Release，运行完整 CTest 与决策笔记校验。
- 更新测试覆盖独立更新器握手、等待宿主退出、成功替换、文件占用及启动失败回滚、离线恢复和用户数据保留。
- 便携包经过 staging 与 ZIP 安全检查，并在全新解压目录核对发行清单、Python、插件和启动行为。
- 同时提供 `XuanHub-v0.5.0-SHA256SUMS.txt`，用于校验 ZIP 的 SHA-256。
- 自动测试与隔离进程验证不代替真实跨远端版本升级、Windows Shell、全部 DPI 及设备服务场景的人工验收。
