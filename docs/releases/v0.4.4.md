# XuanHub v0.4.4

v0.4.4 更新设置窗口与内置主题，并修复重新加载配置时的原生插件崩溃。

## 主要更新

- 设置窗口采用 Qt 6.9.3 自带的 FluentWinUI3 控件，使用左侧导航和分组设置卡片，插件详情更紧凑，低频信息默认折叠。
- 设置窗口关闭后释放视图与 QML 引擎，保留接收异步回执的模型；深浅色同步到控件色板与弹出层。
- 内置主题精简为 WinUI 蓝、青绿、鸢尾紫三套配色，并统一状态栏、插件与弹窗的颜色和间距。
- 玄枢快捷菜单统一 WinUI3 外观并收窄布局；系统信息设置页修正排序提示与操作按钮布局。
- 修复重新加载配置后原生插件元类型引用悬空导致的崩溃：释放插件实例时保留 DLL 代码映像，避免 Qt 缓存访问已卸载代码。同路径原生 DLL 更新仍需先退出宿主。
- 便携包保留 FluentWinUI3、Fusion、Basic 和共享实现及其运行库，确保设置窗口在分发后可用。

## 运行与下载

- Windows 10 / 11 x64。
- 下载 `XuanHub-v0.4.4-portable-x64.zip`，内置 Python 解释器、标准库、插件依赖和 MSVC 运行库，解压后运行 `XuanHub.exe`。
- 升级前退出已有实例，保留自己的配置与凭据文件，避免被默认配置覆盖。
- 旧配置引用已移除的内置主题时回退默认主题，可在设置中重新选择配色；第三方主题仍可加载。
- 发布包使用仓库内置默认配置，不包含打包机器的个人配置、日志、凭据或缓存。

## 发布验证

- 在独立检出目录执行 `pixi run build` 和 `ctest --test-dir build/default -C Release --output-on-failure`。
- 便携包经过 staging 与 ZIP 安全门禁，再在全新解压目录检查 Python、第三方依赖、插件及 Fluent 控件依赖。
- 同时提供 `XuanHub-v0.4.4-SHA256SUMS.txt`，用于校验 ZIP 的 SHA-256。
- 自动测试不代替真实 Shell 嵌入及全部 DPI 场景的人工验收。
