# XuanHub v0.4.2

v0.4.2 包含 v0.4.1 之后的插件生命周期、taskbar 体验修复与新增用量插件。

## 主要更新

- 修复“玄枢菜单”首次展开时按未完成布局的旧高度定位的问题，避免底部 taskbar 模式下弹窗越界；内容尺寸变化后自动重新定位。
- 修复 DPI 变化后嵌入任务栏的窗口尺寸与位置被再次缩放的问题，按原生窗口实际几何恢复布局。
- 将遗留内置插件升级到 SDK V2，统一 Descriptor、配置校验和应用回执，保留外部 V1 插件兼容。
- 改进插件停止与卸载顺序、逐插件配置确认及重试、作用域上下文注入与弹窗服务访问。
- 新增多工具用量与额度监控插件 `py_agent_usage`，提供工具用量、额度和明细面板，可在设置中启用。

## 运行与下载

- Windows 10 / 11 x64。
- 正式包为 `XuanHub-v0.4.2-portable-x64.zip`，内置 Python 解释器、标准库和 MSVC 运行库。
- 解压后运行 `XuanHub.exe`；已有实例须完全退出再启动，才能加载新的 DLL 和 QML。
- 发布包使用仓库内置默认配置，不包含打包机器的配置、日志、凭据或缓存。

## 发布验证

- `pixi run build`。
- `ctest --test-dir build/default -C Release --output-on-failure`。
- 菜单回归覆盖首次展开、动态内容变高、点击关闭与重开、跨插件互斥，并使用 Windows 原生窗口后端核对定位。
- Bundle 便携包经过 staging 与 ZIP 安全门禁，并校验解压后的 Python 运行时和插件文件。
- 自动化几何检查不代替实际 Shell_TrayWnd 嵌入及真实 DPI 切换下的最终视觉验收。
