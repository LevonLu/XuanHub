# 插件多语言开发契约

> 文档导航：[`docs/README.md`](README.md)。本契约同时适用于宿主、C++ 插件和 Python 插件。

XuanHub 首版提供简体中文与英文。中文是源码回退语言；语言包缺项或损坏时，Qt 会显示
源码文字并在 `xuanhub.log` 记录语言包问题。插件不得缓存宿主的显示语言。

## 语言包目录与格式

C++ DLL 插件和 Python 子插件都在自身目录放置 `i18n/zh-CN.json` 与
`i18n/en-US.json`：

```json
{
  "locale": "en-US",
  "contexts": {
    "plugin.clock.main": {
      "上一月": "Previous month"
    }
  }
}
```

插件上下文必须以 `plugin.<插件 id>.` 开头，例如 `plugin.clock.calendar`、
`plugin.py_hello.settings`。宿主会拒绝越过此前缀的上下文，避免插件覆盖核心或其他插件。
同一插件中建议固定使用 `metadata`、`settings`、`main`、`settingsPage` 等页面后缀。
Manifest 的动作 label 固定使用 `plugin.<id>.actions`，由宿主在快捷菜单和托盘中翻译。

`metadata.json` / `plugin.json` 中的插件名使用 `plugin.<id>.metadata`；设置 schema 的
分组名、字段标签、说明、占位符和枚举标签使用 `plugin.<id>.settings`。中英语言包的
上下文与源文字键必须完全一致，英文翻译不得留空。

## QML 与 C++

QML 使用显式上下文，源码文字保持中文：

```qml
Text {
    text: qsTranslate("plugin.demo.main", "加载中…")
}
```

C++ 同样使用显式上下文：

```cpp
QCoreApplication::translate("plugin.demo.main", "加载中…");
```

宿主切换语言时会对状态栏与设置窗口的 QML 引擎调用 `retranslate()`，现有插件对象不会
被销毁。插件可读取上下文属性 `i18n.activeLocale`，将它传给 `Qt.locale()` 处理日期、
数字和日历格式；不要固定 `zh_CN`。

## Python 后端

Python 插件可实现：

```python
def set_locale(locale: str):
    pass
```

worker 会在 `init(config)` 后调用一次，并在语言运行时切换后再次调用。不实现此函数的
旧插件保持兼容。固定错误和状态应从 `update()` 返回稳定码（例如 `networkError`）以及
可选动态明细，由 QML 翻译固定部分；用户输入、服务端返回正文和其他个人数据不翻译。

## 设置枚举

枚举配置必须分离稳定值与显示标签：

```json
{
  "key": "repeatMode",
  "type": "enum",
  "default": "daily",
  "options": [
    { "value": "daily", "label": "每日重复" },
    { "value": "date", "label": "指定日期" }
  ]
}
```

config 只保存 `daily` / `date`。旧字符串数组仍可用，但字符串本身同时充当值和标签，
不适合需要翻译的新插件。若旧版本已经把中文标签写入配置，插件应在读取时兼容，并在
下次保存时迁移为稳定值。

## 事件

C++ 插件可订阅 `app.locale.changed`，payload 含 `locale` 与 `requestedLanguage`；需要
主动获取当前值时发布 `app.locale.request`。订阅对象必须在插件 `shutdown()` 中销毁，
遵守 EventBus 的 DLL 卸载生命周期约束。
