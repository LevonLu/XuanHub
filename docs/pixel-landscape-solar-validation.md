# 像素风景真实太阳验证

验证日期：2026-11-09。范围为 `pixel_landscape` 0.2.0 的定位、太阳计算、六场景光照与插件生命周期；不包括真实天气、月相或地形投影。构建与离屏验收使用 Windows 11、MSVC 2022、Qt 6.9.3 Release。

## 计算与状态

`tests/fixtures/pixel-solar-usno.json` 保存独立的美国海军天文台数据及每条查询地址。太阳计算实现依据 [NOAA 计算说明](https://www.gml.noaa.gov/grad/solcalc/calcdetails.html) 和 [太阳公式](https://www.gml.noaa.gov/grad/solcalc/solareqns.PDF)，参考值来自 [USNO 单日太阳月亮数据接口](https://aa.usno.navy.mil/data/api)，没有用实现自身生成预期值。

| 参考组合 | 覆盖 |
|---|---|
| 北京 2026-06-21、2026-12-21 | 北半球冬夏 |
| 悉尼 2026-12-21 | 南半球夏季、UTC+11 |
| 纽约 2026-03-08 | 春季、夏令时切换日期 |
| 格林尼治 2024-02-29 | 闰日 |
| 基多 2026-09-22 | 赤道、秋分附近 |

日出、日落、太阳正午及民用晨昏共 30 项事件最大偏差 **44 秒**，低于普通纬度 5 分钟目标。另验证南北纬 78°/90° 极昼极夜、数值有限性、纽约春秋夏令时、国际日期线，以及同一 UTC 时刻在不同时区的太阳高度一致。四个纬度的冬夏每两分钟采样一整天，检查光照及晨昏混合连续性，包含太阳午夜回绕。

定位回归使用注入式提供者和私有存储替身：首次未授权不请求、按钮交互请求、请求不重叠、成功缓存、超时降级、缓存过期、手动兜底、权限撤销清缓存、30 分钟刷新、停止中请求、旧结果不能覆盖新配置、坏缓存、未来时间戳及存储失败。手动坐标覆盖成对、类型、有限性、范围和未启用的 `0,0` 不生效。

WM_TIMECHANGE 与恢复供电广播通过合成消息进入同一原生过滤器，验证暂停/禁用动画时仍合并为一次立即重同步，停止后不处理排队更新。这证明消息处理路径，不等同于设备真实休眠验收。

## 渲染和交互

实际 QML 渲染六场景 × 六个时刻（北京夏至 04:10、04:46、07:00、12:16、19:46、22:00）。检查天空与地物同调色、太阳被地形遮挡、窗灯和星月强度变化。太阳位置单独改变不增加静态 Canvas 重绘；正午前后最终色板相同时也不重绘。栏上与弹窗使用相同太阳快照，关闭装饰动画后仍改变光照，动画时间保持不动。

中英文弹窗检查包含定位失败提示、按钮事件以及 700 × 450 逻辑屏幕的窄窗高度约束。Qt 缩放因子 1、1.5、2 的相关渲染测试通过；这属于程序缩放模拟，不是 Windows 显示设置中的实际 DPI 切换。

本地证据在被忽略的 `build/pixel-solar-evidence/`：`solar-day-gallery.png`、`solar-popup.png`、`solar-popup-english-fallback.png` 和 `scale-*/`。离屏平台的 raise/opacity 提示是平台能力告警，检查无 QML 加载或绑定告警。

## 性能口径

同机独立 Qt 离屏探针，每组 25 秒，排除前 10 秒预热；CPU 为占单逻辑核心的百分比，内存为进程私有提交量中位数。原版与新版固定夜雨对照隔离常驻变化；自动晨昏探针每真实秒推进 120 秒，比正式 30 秒校光频繁，用于放大色板刷新成本。不同探针顺序独立运行，不并行压测。

| 探针 | CPU 单核占比 | 私有提交量 MiB | 栏上静态 / 动态绘制次数 |
|---|---:|---:|---:|
| 原版固定夜雨，仅栏上 | 1.245% | 24.83 | 1 / 250 |
| 新版固定夜雨，仅栏上 | 1.349% | 24.68 | 1 / 250 |
| 原版固定夜雨，打开弹窗 | 1.868% | 29.13 | 1 / 248 |
| 新版固定夜雨，打开弹窗 | 0.622% | 29.21 | 1 / 250 |
| 新版自动晨昏加速，仅栏上 | 1.762% | 25.13 | 26 / 275 |
| 新版自动晨昏加速，打开弹窗 | 2.593% | 30.92 | 26 / 275 |

自动晨昏测试为晴天、25 次时间推进，静态绘制为初始 1 次加每次颜色变化 1 次；表中的计数只统计栏上画布，CPU 与内存统计整个探针进程（含打开的弹窗）。正式模式每 30 秒校光，不能直接把加速测试数字当作正常一天的平均消耗。

固定模式弹窗私有内存增加约 0.08 MiB；加速模式比原版固定模式约增加 1.79 MiB，同时包含定位信息区域和太阳图元。25 秒 CPU 样本存在调度与计时波动，尤其新版固定弹窗 CPU 偏低，不能据此宣称性能改善。加速晴天与固定夜雨也不是相同工作负载，只作为刷新压力参考。

结果及重绘次数记录在 `before-*/`、`after-*/`、`solar-*/` 的 `metrics.json`、`probe-*.json` 和 `performance.json`。这是短时插件探针，不代表整台电脑总 CPU、完整宿主常驻内存或长期泄漏验收。
